# PatentAssist.ai

**AI patent drafting and free prior art search** — [patentassist.ai](https://patentassist.ai)

PatentAssist.ai is an AI workspace for patent drafting and prior art search, built for patent attorneys, patent agents, IP law firms, in-house IP teams and inventors.

Start from an invention disclosure and PatentAssist.ai drafts claims first, so you can review and edit them before it writes the complete or provisional specification, abstract and figure descriptions. Drafts follow the format of the patent office you file with: USPTO, EPO, DPMA (German) or IP India.

## Key features

- Claims-first AI patent drafting from an invention disclosure
- Provisional and complete specifications, abstracts and figure descriptions
- USPTO, EPO, DPMA (German) and IP India drafting formats
- AI-generated patent drawings: flowcharts, block diagrams, sectional views
- Free AI prior art search across 20M+ US, EP and Indian patents at [search.patentassist.ai](https://search.patentassist.ai)
- Patentability search reports
- AI copilot for editing drafts
- DOCX export
- EU-hosted AI, no training on customer data, GDPR DPA ([security](https://patentassist.ai/security/))
